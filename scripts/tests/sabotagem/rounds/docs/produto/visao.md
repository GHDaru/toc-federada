# Visão sintética — os defeitos medidos

Base válida da sabotagem de `check-rounds.sh`. Dois defeitos sintéticos, no mesmo formato
que a visão real usa, para o portão ter denominador.

## 6. Defeitos e lições — medidos

**D-01 · Defeito sintético alocado a um round.** Existe para ser alocado exatamente uma
vez, no round 002.

**D-02 · Defeito sintético sem round próprio.** Existe para ser declarado na lista dos que
não viram round — o caso que o portão precisa aceitar sem confundir com esquecimento.
