# Base válida do portão de documentação embutida

> Siglas: **ARA** — Árvore da Realidade Atual · **NC** — Nuvem de Conflito · **RF/RN** —
> requisito funcional / regra de negócio da spec 011.

O que esta base tem, e cada item existe para uma sabotagem poder tirá-lo:

- **duas ferramentas registradas** no domínio sintético (`registrar_raiz_de_ferramenta`) e
  **dois verbetes** no acervo — a sabotagem apaga um verbete (ferramenta descoberta) ou
  acrescenta um verbete sem ferramenta (verbete órfão);
- **duas procedências que resolvem** (uma spec e um ADR sintéticos) — a sabotagem aponta
  uma delas para um arquivo que não existe;
- **uma âncora declarada por componente** (`nc#premissa-sustentada`) que EXISTE no verbete
  — a sabotagem a renomeia;
- **exemplo sintético** em cada verbete — a sabotagem apaga um.

O denominador do portão é o registro do SERVIÇO, e é por isso que o domínio sintético
existe aqui: sem ele, o portão conferiria o acervo contra ele mesmo, que é o defeito que
ele existe para não repetir (duas ferramentas documentadas de seis, na quarta geração).
